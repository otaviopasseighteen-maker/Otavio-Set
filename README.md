# THE PASS — Portfólio de Otavio Passarelo

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript puro para a disciplina de Desenvolvimento Web I.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: identidade visual, layout e responsividade.
- `js/script.js`: menu mobile e atualização automática do ano.
- `assets/images/`: pasta reservada para imagens dos projetos.

## Tecnologias
HTML5, CSS3 (Flexbox, Grid e Media Queries) e JavaScript puro. O projeto não utiliza frameworks JavaScript nem bibliotecas/frameworks de estilização.

## Projetos apresentados
- Saúde & Vida
- Persona 5
- Detroit: Become Human
- P5R-AGENT (projeto pessoal em desenvolvimento)

As descrições dos projetos poderão ser detalhadas e complementadas com imagens conforme o portfólio evoluir.
